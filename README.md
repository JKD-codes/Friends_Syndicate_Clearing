## 🌐 Website Architecture & Design System

The platform is designed with a classic, editorial aesthetic inspired by the Kumud Logistics design system:
- **Color Palette**: Warm ivory base (`#F7F4EF`), dark carbon navy backdrop (`#0F1218` & `#14171C`), and rich aged brass golden accents (`#B5824A`).
- **Typography**: Editorial serif headings (`Fraunces`) paired with crisp corporate body sans (`Inter`) and technical metadata mono (`JetBrains Mono`).
- **Zero-Backend Architecture**: Optimized as a client-side corporate showcase. All customer inquiries and quotes route directly to verified executive communication channels via WhatsApp (`wa.me/919867326056`) and direct telephonic links (`tel:+919867326056`), eliminating ticketing delays and unnecessary backend complexity.
- **100% Mobile Responsive**: Dedicated full-screen slide-in mobile navigation drawer with backdrop blur, touch-friendly tap targets, and sticky executive WhatsApp access.

## 🚀 Development & Build

This project uses [Vite](https://vitejs.dev/) for bundling and local development.

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production-ready bundle into /dist
npm run build

# Preview production build locally
npm run preview
```
